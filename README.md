# DLA — Deutsch Lernen mit Ata

Interaktives Arbeitsblatt **Deutsch A2** (Haus und Zimmer · Kleidung · Wo? · Präpositionen · Fragen und Antworten).

- 10 Übungen, insgesamt 98 Punkte
- Automatische Auswertung mit Lösungen
- Antworten werden im Browser gespeichert
- Heller/dunkler Modus, druckbar

Reine statische Website (`index.html`, `styles.css`, `app.js`) — kein Build-Schritt nötig.
